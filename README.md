💰 Controle Financeiro Pessoal

Um sistema simples, visual e intuitivo para organizar, acompanhar e controlar suas finanças pessoais.

📌 Sobre o Projeto

Este projeto permite registrar receitas e despesas, acompanhar o saldo disponível e visualizar de forma clara como seu dinheiro está sendo utilizado.

Através de uma interface prática, é possível cadastrar movimentações financeiras, consultar o histórico e acompanhar os principais indicadores da sua vida financeira.

🚀 Tecnologias Utilizadas

🏗 HTML → Estrutura da aplicação
🎨 CSS → Estilização, layout e responsividade
🎮 JavaScript → Lógica do sistema e interatividade
📊 Gráficos → Visualização das receitas e despesas

🎮 Como Usar?

Informe o valor e o tipo da movimentação.

Escolha entre receita ou despesa.

Adicione uma categoria e uma descrição.

Consulte o saldo atualizado automaticamente.

Acompanhe suas movimentações e gráficos financeiros.

✨ Funcionalidades

💵 Cadastro de receitas e despesas
📊 Dashboard com resumo financeiro
💰 Cálculo automático do saldo
📈 Gráficos para acompanhar os gastos
🏷️ Organização por categorias
📋 Histórico de movimentações
🗑️ Exclusão de registros
📱 Layout responsivo para celular e computador
💾 Armazenamento dos dados no navegador

📷 Demonstração

🎯 Objetivo

O objetivo deste projeto é facilitar o controle das finanças pessoais, permitindo visualizar de maneira rápida e organizada quanto entra, quanto sai e qual é o saldo disponível.
